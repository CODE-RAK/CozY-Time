## ✨ Overview

Cozy Time transforms everyday timekeeping into a relaxing experience.

It brings together three useful tools in one beautifully styled interface, with seven visual themes, customizable alarms, and automatic browser-based saving.

**Simple to use. Beautiful to look at. Designed to feel cozy.**

Switch themes instantly using the coloured dots in the header or press `T`.

## 💾 Your Preferences Stay Saved

Cozy Time uses browser storage to preserve your experience.

- Selected theme
- Clock format
- Alarm preferences
- Uploaded ringtone
- Selected tab
- Stopwatch and timer timing states

A **Clear Saved Data** option is available whenever you want a fresh start.

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd cozy-time
```

### 3. Run Cozy Time

Open `index.html` in your browser.

No build process or complicated installation is required.

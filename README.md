## ✨ Overview

Cozy Time transforms everyday timekeeping into a relaxing experience.

It brings together three useful tools in one beautifully styled interface, featuring seven visual themes, customizable alarms, and automatic browser-based saving.

**Simple to use. Beautiful to look at. Designed to feel cozy.**

## 🎨 Explore the Themes

Seven carefully selected themes give Cozy Time a different atmosphere.

| Theme | Atmosphere |
|:---|:---|
| ☕ **Cozy Cocoa** | Warm coffee-inspired aesthetic |
| 🌿 **Sage Garden** | Soft natural greens |
| 💜 **Lavender Dusk** | Relaxing purple tones |
| 🍑 **Peach Glow** | Gentle pastel warmth |
| 🌊 **Ocean Mist** | Calm ocean-inspired colours |
| 🪔 **Diwali Glow** | Golden festive sparks |
| 🎄 **Christmas Eve** | Winter-inspired snowfall |

Switch themes instantly using the coloured dots in the header or press `T`.

## 💾 Your Preferences Stay Saved

Cozy Time uses browser storage to preserve your experience.

- Selected theme
- Clock format
- Alarm preferences
- Uploaded ringtone
- Selected tab
- Stopwatch and timer timing states

Close the website and return later without losing your saved timing progress.

A **Clear Saved Data** option is available whenever you want a fresh start.

## ⌨️ Keyboard Shortcuts

| Key | Function |
|:---:|:---|
| `T` | Cycle through themes |

## 🛠️ Built With

Cozy Time is a standalone, single-file web application.

| Technology | Purpose |
|:---|:---|
| HTML5 | Application structure |
| CSS3 | Styling, animations and themes |
| JavaScript | Clock, stopwatch, timer and alarm logic |
| Browser Storage | Saving preferences and timing states |
| Web Audio API | Alarm playback |

**Everything runs from one HTML file.**

No separate CSS or JavaScript files. No frameworks. No build tools.

## ⚡ Getting Started

### Option 1 — Try Online

Visit the live website:

**[☕ Open Cozy Time](https://code-rak.github.io/CozY-Time/)**

### Option 2 — Download and Run

1. Download `index.html` from this repository.
2. Open the downloaded file in your browser.
3. Start using Cozy Time!

### Option 3 — Clone the Repository

```bash
git clone https://github.com/CODE-RAK/CozY-Time.git
```

Open the project folder and double-click `index.html`.

**No installation. No dependencies. Just one HTML file.**

## 🌍 Deployment

Cozy Time is hosted using GitHub Pages.

To deploy your own copy:

1. Fork this repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/root`.
5. Click **Save**.

Your website will be available through your GitHub Pages URL.
